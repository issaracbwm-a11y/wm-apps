# เชื่อมทะเบียน Google Sheets กับเว็บเจ้าหน้าที่

ชีต: ใช้ปุ่ม เปิดชีตทะเบียน ในหน้า ข้อมูลกลางของทีม

เจ้าของ: บัญชี Google ที่หน่วยงานกำหนด

ชีตทะเบียนเริ่มต้นมี 1,850 เครื่องจากฐานกลาง และแท็บอ้างอิง Excel 889 แถว ซึ่งเป็นรายสถานประกอบการ ไม่ใช่ทะเบียนรายเครื่องทั้งหมด ทุกแถวเริ่มเป็น “รอตรวจสอบ” ไม่ใช่ผลยืนยัน Back Office รอบใหม่

## ติดตั้งครั้งแรก
1. สร้าง Apps Script ในบัญชีเจ้าของชีต วาง Code.gs แล้วบันทึก
2. เผยแพร่ Web app: ทำงานเป็นเจ้าของ และเข้าถึง Anyone โดยโค้ดตรวจตั๋วอ่านข้อมูลใช้ครั้งเดียวก่อนอ่านชีต ชีตยังเป็นส่วนตัว
3. อนุญาตการอ่านชีตและติดต่อ Supabase ตามหน้าสิทธิ์ของ Google
4. นำ URL /exec ใส่หน้า ข้อมูลกลางของทีม > ตั้งค่าการเชื่อมต่อครั้งแรก บนอุปกรณ์ผู้ดูแล
5. กดดึงข้อมูล ตรวจทานรายการเปลี่ยน แล้วกดยืนยันนำเข้า

## ใช้งานประจำ
Claude อัปเดตจาก Back Office หลังได้รับอนุญาตและเข้าใช้งานระบบได้จริง ผู้ดูแลกดนำเข้าจากชีตภายหลัง เว็บยังไม่เชื่อม Back Office อัตโนมัติ

รับเฉพาะแถวตรวจสอบแล้ว มีวันที่ตรวจสอบ ผู้ปรับปรุง และหลักฐานอ้างอิง จับคู่ด้วยรหัสเครื่องหรือเลขเครื่อง ไม่ใช้ชื่ออย่างเดียว ช่องว่างไม่ล้างค่าเดิม ไม่ลบเครื่องที่หายจากชีต ไม่ทับพิกัดที่เจ้าหน้าที่แก้ ผลตรวจ แผนตรวจ หรือหมายเหตุภาคสนาม

## อัปโหลดเว็บ
อัปโหลด ZIP รุ่นนี้เป็น deployment ใหม่ของโครงการ Cloudflare Pages เดิม wm-truck-scales-staff ไม่สร้างโครงการชื่อใหม่ เพื่อคง URL และสิทธิ์อุปกรณ์เดิม

## คำสั่งสำหรับ Claude
ใช้บัญชี Google เจ้าของชีตที่ผู้ใช้กำหนด เปิดชีตข้างต้น อ่านแท็บ วิธีอัปเดต ก่อนทำงาน เข้า Back Office เฉพาะสิทธิ์ที่ผู้ใช้อนุญาต ห้ามอ้างว่าเข้าระบบได้หากยังเข้าไม่ได้

อัปเดตแท็บ ทะเบียนเครื่องชั่งรถยนต์ ตามหลักฐานจริง จับคู่เลขเครื่อง/รหัสเครื่อง ตรวจจังหวัดสุราษฎร์ธานีและนครศรีธรรมราช ห้ามเปลี่ยนรหัสรายการเว็บเดิม ห้ามลบแถวหรือเปลี่ยนชื่อคอลัมน์ ห้ามทับสูตรคอลัมน์ AE

ตรวจวันหมดอายุ เลขคำขอ วันยื่น สถานะรายเครื่อง และผู้รับผิดชอบ ไม่ถือว่าคำขอระดับสถานที่ยืนยันทุกเครื่อง ถ้าค้นไม่พบให้บันทึกไม่พบในระบบ ห้ามสรุปว่าไม่ยื่นโดยไม่มีหลักฐาน ถ้ามีข้อขัดแย้งให้ระบุข้อมูลขัดแย้ง พิกัดต้องมีหลักฐานและไม่เดา

แถวที่ยืนยันแล้วให้ใส่ Z=ตรวจสอบแล้ว AA=วันที่ตรวจสอบจริง AB=ผู้ปรับปรุง AC=หลักฐานอ้างอิง Back Office ใช้วันที่ ค.ศ. YYYY-MM-DD และสถานะยื่นคำขอแล้วเมื่อมีเลขคำขอและวันยื่นครบ เก็บหมายเลขเครื่องและรหัสเป็นข้อความเพื่อรักษาศูนย์นำหน้า

รายงานจำนวนที่ตรวจ พบใหม่ อัปเดต ไม่พบ และต้องตรวจเพิ่ม พร้อมรายการที่ยังไม่เสร็จ ไม่กดนำเข้าเว็บแทนผู้ดูแล และไม่แก้ข้อมูลภาคสนามใน Supabase
