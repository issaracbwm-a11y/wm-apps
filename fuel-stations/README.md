# แผนที่จุดตรวจสถานีบริการน้ำมันเชื้อเพลิง

หน้าแผนที่สำหรับเจ้าหน้าที่ ชว.สุราษฎร์ธานี แสดงสถานีบริการ จ.สุราษฎร์ธานี และ จ.นครศรีธรรมราช ตามทะเบียนใน WM Smart Inspection

- เข้าสู่ระบบด้วยบัญชี Smart Inspection แล้วอ่านข้อมูลตามสิทธิ์บัญชี (RLS) แบบอ่านอย่างเดียว:
  `establishments` (type_code = fuel), `fuel_cert_batches` (ชุดปัจจุบัน), `inspection_jobs` (module = fuel-dispenser, ไม่รวมฉบับร่าง)
- ซอร์สนี้ไม่มีข้อมูลสถานี ข้อมูลโหลดหลังเข้าสู่ระบบ และเก็บสำเนาในเบราว์เซอร์ไว้ดูตอนไม่มีสัญญาณ (ล้างเมื่อออกจากระบบ)
- ไม่ต้องแก้ฐานข้อมูลหรือ Smart Inspection: ปุ่ม "เริ่มตรวจใน Smart Inspection" เปิด `/jobs/new?est=<UUID>` ซึ่งเลือกสถานีไว้ให้ ยังไม่สร้างงานจนกว่าเจ้าหน้าที่กดยืนยัน
- สีหมุด: ตรวจแล้วในปีงบปัจจุบัน = เขียว (ทับสีคำรับรอง) · หมดอายุ = แดง · ใกล้หมดอายุ ≤ 60 วัน = ส้ม · ยังไม่หมดอายุ = เหลือง · ไม่พบชุดคำรับรอง/วันสิ้นอายุ = เทา
  สถานะคำรับรองอ้างอิงวันสิ้นอายุที่เร็วที่สุดของชุดคำรับรองปัจจุบันในทะเบียน ไม่ใช่สถานะคำรับรองทางราชการ และผลตรวจไม่เปลี่ยนวันสิ้นอายุ
- สถานีที่พบในพื้นที่แต่ไม่มีในทะเบียน: หน้านี้ไม่บันทึกเอง แสดงพิกัดและสถานีใกล้เคียง แล้วส่งต่อไปเพิ่มใน Smart Inspection
- ค่า Supabase ในโค้ดเป็น URL และ publishable key ที่เปิดเผยอยู่แล้วในเว็บ Smart Inspection — ห้ามใส่ secret / service-role key
